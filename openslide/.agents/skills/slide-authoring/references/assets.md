# Ресурсы и места для изображений

## Ресурсы отдельной презентации

Файлы, используемые только в одной презентации, размещай в `slides/<id>/assets/`. Импортируй как ES-модули:

```tsx
import hero from './assets/hero.jpg';
// …
<img src={hero} style={{ width: '100%', height: '100%', objectFit: 'cover' }} />
```

Если нужен только URL:

```tsx
const videoUrl = new URL('./assets/intro.mp4', import.meta.url).href;
```

## Общие ресурсы

Файлы для нескольких презентаций или тем — логотипы компании, аватары докладчиков, повторяющиеся значки — размещай в `assets/` в корне проекта. Импортируй через псевдоним `@assets`:

```tsx
import logo from '@assets/logos/acme.svg';
```

В `themes/*.md` путь может быть указан в тексте, например «используй `@assets/logos/acme.svg` рядом с заголовком». В самой презентации нужен явный импорт.

Для полностью текстовой презентации не создавай `slides/<id>/assets/`.

## Места для изображений (`<ImagePlaceholder>`)

Когда нужен конкретный файл, **который должен предоставить пользователь**, — снимок продукта, фото команды, диаграмма по его данным, — оставь типизированное место для загрузки вместо выдуманного изображения:

```tsx
import { ImagePlaceholder } from '@open-slide/core';

<ImagePlaceholder hint="Главный снимок экрана продукта" width={1280} height={720} />
```

Пользователь загружает файл через панель Assets, выбирает место для изображения в инспекторе и нажимает Replace… («Заменить…»). JSX заменяется на настоящий `<img>` с добавлением импорта.

**Оставляй место только для конкретного изображения**, необходимого по содержанию презентации. Примеры: показ продукта со снимками функций; отчёт о встрече команды с общим фото; описание клиентского проекта с логотипом заказчика и снимком панели аналитики.

**Не оставляй пустые места** ради украшения, случайных стоковых фото, крупной иллюстрации на перегруженном текстом слайде или там, где достаточно типографики, значков и графики. Если содержание можно передать шрифтом, макетом и цветом, так и сделай. Каждое пустое место требует действий пользователя; добавляй его только по необходимости.

Размер должен соответствовать выделенной области. Передавай `width`/`height` при фиксированном размере изображения; опускай их, если компонент заполняет ячейку flex/grid. В `hint` описывай нужное **содержимое** («Диаграмма выручки за третий квартал»), а не роль («главная картинка»).

### Типичные ошибки

- ❌ `<ImagePlaceholder>` на разных слайдах «для выразительности». Он предназначен для материалов пользователя, а не для случайных фото.
- ❌ Место для загрузки вместо значка или декоративной фигуры. Используй типографику или SVG.
