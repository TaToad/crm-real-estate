# Плавное преобразование элементов (`MorphElement`)

> Преобразование основано на `SlideTransition`. Сначала прочитай `transitions.md`, если ещё не читал.

Если на соседних слайдах есть **один и тот же визуальный объект**, движок может плавно изменить его положение, размер, радиус скругления и цвета вместо исчезновения и повторного появления. В Keynote это называется Magic Move. Для включения:

1. На **обоих** слайдах оберни объект в `MorphElement` с **одинаковым `id`**.
2. Включи `morph` в переходе входящего слайда.

```tsx
import { MorphElement, type Page, type SlideTransition } from '@open-slide/core';
import type { CSSProperties } from 'react';

// Преобразование: удержание старого слайда и появление нового только через прозрачность оставляют движение копиям, см. правила.
const morphTransition: SlideTransition = {
  duration: 280,
  exit:  { duration: 308, easing: 'cubic-bezier(0.4, 0, 1, 1)', keyframes: [{ opacity: 1 }, { opacity: 1 }] },
  enter: { duration: 308, easing: 'cubic-bezier(0, 0, 0.2, 1)', keyframes: [{ opacity: 0 }, { opacity: 1 }] },
  morph: { duration: 868, easing: 'cubic-bezier(0.4, 0, 0.2, 1)' },
};

const stage: CSSProperties = { width: '100%', height: '100%', position: 'relative', background: '#000000', overflow: 'hidden' };

const Narrow: Page = () => (
  <div style={stage}>
    <MorphElement id="pill"><div style={{ position: 'absolute', left: 842, top: 479, width: 236, height: 122, borderRadius: 999, background: '#ffffff' }} /></MorphElement>
  </div>
);
const Wide: Page = () => (
  <div style={stage}>
    <MorphElement id="pill"><div style={{ position: 'absolute', left: 721, top: 479, width: 478, height: 122, borderRadius: 999, background: '#0a0a0a' }} /></MorphElement>
  </div>
);

Wide.transition = morphTransition;   // вперёд: Narrow → Wide преобразует овальный элемент
Narrow.transition = morphTransition; // назад: Wide → Narrow возвращает его прежний вид
```

## Требования

- `morph: true` наследует `duration`/`easing` перехода. Объект `{ duration?, easing?, delay? }` позволяет настроить преобразование независимо от плавной смены слайдов. Обычно преобразование лучше смотрится в 2–4 раза дольше появления: например 280 мс для появления и 868 мс для преобразования. На слайдах с `morph` смена прозрачности может длиться дольше диапазона 200–280 мс из `transitions.md`, поскольку согласуется с преобразованием. Для остальных слайдов диапазон сохраняется.
- Элементы сопоставляются по `id`. Для пары движок выполняет FLIP-преобразование: измеряет оба прямоугольника, копирует уходящий элемент в слой над обоими слайдами, скрывает оригиналы и анимирует преобразование, скругление и цвета. Толщина границ анимируется в отдельной рамке, чтобы не растягиваться вместе с блоком. Каждый `id` должен быть уникален в пределах слайда. Не вкладывай `MorphElement` друг в друга.
- Элемент с `id` только на одной стороне появляется или исчезает **на месте**. Так к ряду добавляется третий блок: прежние плавно перемещаются, новый проявляется.
- Цвета узла и его дочерних элементов тоже плавно меняются: надпись может переходить из чёрной в белую во время движения.
- Переход задаётся на **входящем** слайде. Для работы при возврате назначь один объект перехода обоим слайдам, как в примере.

## Семь правил, проверенных на реальных презентациях

1. **Предпочитай удержание уходящего слайда и изменение только прозрачности входящего.** Любое семейство переходов технически совместимо с преобразованием: общие прямоугольники измеряются до начала фаз. Но `transform` у входящего слайда двигает остальное содержимое одновременно с копиями объектов, создавая конкурирующие движения. Передай движение копиям, а новый слайд плавно покажи над старым. Прозрачность уходящего слайда движок всё равно удерживает, см. `transitions.md`. Оригиналы преобразуемых элементов скрыты через `visibility`, поэтому дубликатов не видно.
2. **Геометрия должна быть определена при монтировании.** Прямоугольники фиксируются один раз в момент смены. Позиционируй элементы постоянными пиксельными значениями, не результатом измерения в эффекте после монтирования: повторный рендер сдвинет цель и вызовет скачок. Если текст внутри постепенно растёт, например печатается по буквам, добавь скрытый заполнитель полной ширины для неизменного размера блока.
3. **Не задавай `transform` самому преобразуемому узлу.** Процентный сдвиг `translate(-50%, -50%)` неверно масштабируется и смещает копию на десятки пикселей. Преобразования центрирования и позиционирования задавай обычному `<div>`, оборачивающему `MorphElement`.
4. **`MorphElement` объединяет `className`/`style` с единственным дочерним DOM-элементом** и не создаёт обёртку. Для области обрезки с `overflow: hidden` и фиксированной шириной нужен явный вложенный `<div>`. Иначе область схлопнется до внутреннего `<img>` и сожмёт его.
5. **Включай анимацию появления только при `useIsActivePage()`.** При смене движок монтирует новый экземпляр уходящего слайда, чтобы снять его конечное состояние. Редактор также монтирует все слайды для миниатюр и обзора. Если там повторяется вступительная анимация, снимок фиксирует промежуточное состояние и преобразование начинается неверно. Хук возвращает `true` только для экземпляра, который видит аудитория. Остальные — снимок уходящего слайда, миниатюры, обзор, предпросмотр докладчика, печать — должны показывать конечное состояние без вступления, с полным текстом.

   ```tsx
   import { useIsActivePage } from '@open-slide/core';

   // Внутри компонента слайда:
   const animate = useIsActivePage();
   ```

6. **Копии движутся поверх всего.** Слой преобразования расположен над обоими слайдами. Элемент, который должен появиться после прибытия копии, иначе покажется раньше времени. Задержи его появление на длительность преобразования: `animation: 'osd-fade 0.63s ease-out 0.868s both'`, где `0.868s` — `morph.duration`. Движок не предоставляет `osd-fade`: объяви `@keyframes osd-fade { from { opacity: 0 } to { opacity: 1 } }` в презентации. Длительность храни в общей константе, чтобы значения не разошлись.
7. **Слайд с фиксацией состояния — отдельный компонент.** Переход принадлежит входящему слайду. Чтобы после преобразования показать то же содержимое обычной мгновенной сменой, создай второй компонент без `.transition`, например `const Flow4Hold: Page = () => <Flow count={4} />`.

## Когда применять

Для **непрерывности состояния**: бегунок переключателя перемещается к другому варианту; карточка раскрывается в подробности; логотип из центра переходит в схему следующего слайда; в ряду появляется ещё один блок. Сам объект связывает мысль между слайдами. Не преобразуй декор и не добавляй идентификаторы «на всякий случай»: каждый `id` обещает зрителю, что это тот же объект. Одной-двух таких последовательностей на раздел достаточно; окружающие слайды сменяй мгновенно или плавным появлением.
