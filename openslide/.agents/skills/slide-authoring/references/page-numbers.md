# Номера слайдов (`useSlidePageNumber`)

Для номера в нижнем колонтитуле (`03 / 12`, «Слайд 3» и т. п.) используй `useSlidePageNumber()`. **Никогда не задавай `n` / `TOTAL` вручную**, иначе при добавлении, перестановке или удалении слайда придётся менять все колонтитулы.

```tsx
import { useSlidePageNumber } from '@open-slide/core';

const Footer = () => {
  const { current, total } = useSlidePageNumber();
  return (
    <span>{String(current).padStart(2, '0')} / {String(total).padStart(2, '0')}</span>
  );
};
```

`current` нумеруется с 1, как видит пользователь; `total` — число слайдов в презентации. Хук работает в основном просмотре, миниатюрах, сетке обзора, режиме показа, окне докладчика и экспорте HTML/PDF. Один и тот же JSX `<Footer />` подходит везде. Вызывай хук внутри компонента, используемого **на каждом слайде**, а не на верхнем уровне модуля.
