# OpenSlide — руководство для агента

В этом проекте ты создаёшь **презентации**. Каждая презентация — React-код, который ты пишешь; отдельный слайд представлен компонентом `Page`.

## Обязательные правила

- Размещай презентацию в `slides/<kebab-case-id>/`.
- Точка входа — `slides/<id>/index.tsx`.
- Изображения, видео и шрифты для одной презентации размещай в `slides/<id>/assets/`. Общие для нескольких презентаций или тем ресурсы, например логотипы и аватары, — в корневом `assets/` с импортом через `@assets/...`.
- **Не меняй** `package.json`, `open-slide.config.ts` и другие презентации.
- Не добавляй зависимости. Используй только `react` и стандартные веб-API.

## Какой навык выбрать

- **Новая презентация** — `create-slide`: уточнение задачи, структура, передача результата.
- **Правки по комментариям инспектора**, то есть маркерам `@slide-comment` на слайде, — `apply-comments`.
- **Создание темы оформления или выделение её из презентации** — `create-theme`. Темы находятся в Markdown-файлах `themes/<id>.md`; `create-slide` читает их до создания презентации.
- **Ссылки «этот слайд» / «этот элемент»** без конкретного имени — сначала `current-slide`. Он читает `node_modules/.open-slide/current.json` сервера разработки, чтобы определить презентацию, слайд и выбранный в инспекторе элемент.
- **Текст выступления и заметки докладчика** — встроенный экспорт `notes` в `index.tsx`. Его индексы совпадают с массивом слайдов; заметки видны в окне докладчика. См. «Заметки докладчика» в `slide-authoring`. Никогда не выдавай текст выступления отдельным Markdown- или текстовым файлом.
- **Любое другое изменение слайда** — сначала `slide-authoring`. Это технический справочник для `slides/<id>/`: требования к файлу, рабочая область 1920×1080, размеры шрифта, палитра, макет, ресурсы, проверка и типичные ошибки. `create-slide` и `apply-comments` используют эти же правила.

Используй естественные русские термины: «презентация», «слайд», «макет», «заметки докладчика». Полный список соответствий — в разделе «Терминология» навыка `slide-authoring`. В путях и API слово `slide` может обозначать целую презентацию, а `Page` — один слайд. Технические имена не переводи.

Сохраняй это руководство коротким: только обязательные правила. Подробности находятся в навыках выше.

## Обновление навыков

Перечисленные навыки управляются пакетом `@open-slide/core`. Не редактируй установленные копии на месте. Для обновления выполни:

```
pnpm up @open-slide/core
pnpm sync:skills
```

`pnpm dev` также проверяет расхождения при запуске и предлагает синхронизацию. Команда `pnpm sync:skills --dry-run` через `pnpm exec open-slide sync:skills --dry-run` показывает изменения без записи.
